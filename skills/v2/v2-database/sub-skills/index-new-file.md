# 新文件建库 (index) 详细用法

## 何时建库

当 `v2_db lookup <函数名>` 返回 `NOT_FOUND` 时, 说明该函数所在文件尚未索引。

## 建库命令

```bash
v2_db index <文件相对路径>
```

文件路径相对于源码根目录 (DVS_SOURCE_ROOT)。

## 建库流程

1. 检查该文件是否已索引 (避免重复)
2. 使用 tree-sitter 精确解析所有函数定义
3. 提取函数名、签名、行号范围、函数体哈希
4. 存入 functions.db (不存函数体文件, 需要时按行读原文件)
5. 建库后可 `v2_db lookup <函数名>` 查询

## 无 tree-sitter 时

自动降级为正则提取 (精度较低, 但基本可用)。
